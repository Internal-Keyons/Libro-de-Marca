Cómo utilizar este manual

Este libro reúne los principios, componentes y patrones que orientan el diseño de experiencias digitales consistentes, accesibles y adaptadas a cada producto.

  1. Encuentra lo esencial

    Explora los módulos para localizar principios, componentes,
    patrones y especificaciones relacionados con tu tarea.

  2. Interpreta las normas

    DEBE y NO DEBE establecen requisitos; DEBERÍA
    orienta decisiones y PUEDE ofrece alternativas.

  3. Vigencia y alcance

    Consulta qué normas están vigentes y dónde se aplican:
    productos Keyons, herramientas internas y clientes.

  4. Diseña y verifica

    Aplica las reglas junto con sus ejemplos y criterios
    de comprobación para construir experiencias coherentes.

Explore una interfaz con las reglas de Keyons, sin empezar de cero.

Para diseñadores y desarrolladores. Lo que se crea aquí es una dirección visual para revisar, no un producto final: todo pasa por revisión antes de aplicarse.
