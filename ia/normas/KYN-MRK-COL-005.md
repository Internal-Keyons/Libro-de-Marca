# KYN-MRK-COL-005 · Combinaciones

Número: 7.5 · Estado: vigente · Capítulo: 07 Color · Fuente: `/fundamentos/color/paleta-base.html#contraste`

##### Qué combinación sirve para qué

Mínimo 4.5:1 para texto normal y 3:1 para texto grande y elementos gráficos.

| Texto sobre fondo | Contraste | Uso |
|---|---|---|
| Noche sobre Blanco | 16.7 : 1 | Todo |
| Noche sobre Cielo | 6.5 : 1 | Todo |
| Noche sobre Salmón | 4.9 : 1 | Todo |
| Cielo sobre Noche | 6.5 : 1 | Todo |
| Atardecer sobre Noche | 8.6 : 1 | Todo |
| Blanco sobre Salmón | 3.8 : 1 | Solo texto grande y logotipo |
| Cielo sobre Blanco | 2.6 : 1 | Nunca texto; solo superficies |
